## 学习路线

1. 先阅读后端或前端的合并笔记，建立完整系统地图。
2. 遇到细节时，回到对应集数的逐字稿或逐字稿状态页查上下文。
3. 对照参考仓库运行代码，优先完成后端接口，再验证前端联调。
4. 课程字幕中的识别错误和错配内容，以视频和实际代码为准。
