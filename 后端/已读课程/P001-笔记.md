<h2 id="section-0">项目与学习对象</h2>

- 苍穹外卖是前后端分离的外卖点餐项目：商家在线发布、销售菜品；用户通过微信小程序点餐、支付。（00:00:10–00:00:35）
- 面向已学 Java SE、Java Web、需要项目实践的学习者；老师也提到计算机相关专业准毕业生，以及希望了解前后端分离、Vue + Spring Boot 的在职开发者。毕业设计通过率等说法属于课程推介，不是技术结论。（00:00:35–00:01:33）

<h2 id="section-1">相对瑞吉外卖的变化</h2>

- 开发方式：传统开发 → 前后端分离。（00:02:11–00:02:23）
- 用户端：H5 → 微信小程序。（00:02:23–00:02:31）
- 服务端：有状态 → 无状态，课内给出的目的为方便水平扩展；本节未解释实现方式。（00:02:31–00:02:40）
- 新增内容：订单支付、订单管理、统计报表、工作台、来单提醒、客户催单。（00:02:40–00:02:51）
- 学习建议：刚开始瑞吉外卖可转学苍穹外卖；瑞吉外卖快学完的，可重点学习新增模块。（00:03:12–00:03:30）

<h2 id="section-2">课程安排</h2>

- 三大模块：基础数据、点餐业务、统计报表；模块相对独立。例如只想了解报表开发，可直接学习统计报表模块。（00:03:35–00:04:04）
- 老师计划在课程末尾补充前端课程，用来开发本项目功能；这是录制时的计划，本节没有展开前端教学。（00:04:04–00:04:30）
