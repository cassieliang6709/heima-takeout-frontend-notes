# 苍穹外卖 · 后端篇

> 以黑马程序员《苍穹外卖》后端课程 P1–P170 为范围，按“课程原意 → 项目逻辑 → 代码验证”的方式整理。

这里的后端课程不是 Open Transcript 项目本身，而是 Open Transcript 用来处理的目标课程：黑马外卖（苍穹外卖）的 Java 后端部分。

## 从这里开始

- [已完整读取字幕的课程 · P1–P4](已读课程索引.md)：原始 SRT、逐字稿和基于全文的笔记。其余 P5–P170 尚未完成。
- [后端篇 · 合并大笔记](苍穹外卖 · 后端篇 · 合并大笔记.md)：按业务链路梳理项目，不按视频字幕碎片堆叠。
- [后端篇 · 逐字稿导入状态](苍穹外卖 · 后端篇 · 逐字稿导入状态.md)：P1–P170 的完整分集目录、时长和字幕状态。
- [前端学习笔记](../前端学习笔记 · 合并大笔记.md)：对应 P171–P199 的前端部分。

## 学习顺序

1. 先看总笔记的系统地图，知道每个模块解决什么问题。
2. 按 Day 1–12 阅读业务章节，边看视频边对照项目代码。
3. 需要回到视频时，在逐字稿状态页按 P 集数定位。
4. 最后用每章的验证清单复现接口、数据库和缓存行为。
